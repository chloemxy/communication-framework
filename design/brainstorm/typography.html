1. Hyperlegible

A health-literacy tool set in a typeface built for low-vision readers. The character is the letterforms themselves: the tailed l, the slashed-looking zero, the open apertures that make Atkinson look unlike any other sans.

Interface and wordmark
Atkinson Hyperlegible Next (Braille Institute) 400/600/800. Every confusable pair is drawn apart: I, l and 1 differ, 0 and O differ, rn does not read as m. Large x-height.
Reading
Literata 400/600 (designed for long reading on screens, optical sizes, sturdy serifs, generous x-height). Pairs well with Atkinson's open, slightly wide shapes.
Wordmark
PRISM in Atkinson 800, 21px: the only 800 in the interface besides Display.

DESIGN.md Type changes

  • Faces change (both).
  • Add weight 800 for Display and the wordmark only.
  • Body moves 14 to 15, reading 15 to 17 (Atkinson and Literata both set large; 17 is closer to print handout size).

Stays

  • No italics, uppercase (wordmark excepted, it already is) or letter-spacing.
  • Seven treatments plus the wordmark; nothing under 13px; tabular numbers.
--sans:'Atkinson Hyperlegible Next', system-ui, sans-serif;
--serif:'Literata', Georgia, serif;
--fs-xs:13px;  /* caption */
--fs-sm:15px;  /* body */
--fs-md:17px;  /* reading (serif) */
--fs-lg:19px;  /* heading */
--fs-2xl:28px; /* display, 800 */
--fs-mark:21px; /* wordmark, 800 */

2. Health column

The editorial health page: a newspaper masthead and serif headlines over a plain government-sans interface. PRISM reads as a desk that publishes, not a form that processes.

Interface
Public Sans 400/600, unchanged. Keeps the U.S. Web Design System link and every control as it is.
Reading, display and wordmark
Newsreader (Production Type, drawn for on-screen news) 400/600 with an italic. Optical sizes: tight and crisp at 72 for the masthead, sturdier at text size. Lining tabular figures for item numbers.
Wordmark
PRISM in Newsreader 600 at display optical size, 23px, tracked +0.07em like a masthead.

DESIGN.md Type changes

  • The serif moves out of the document into Display, page Heading, score-sheet item numbers and the wordmark.
  • One italic: titles of cited sources (User's Guide, journal names), as an editor would set them.
  • Letter-spacing on the wordmark only.
  • Reading 15 to 17 (Newsreader has a smaller x-height than Source Serif).

Stays

  • Public Sans everywhere else; weights 400/600; no uppercase in running text; nothing under 13px.
--sans:'Public Sans', system-ui, sans-serif;
--serif:'Newsreader', Georgia, serif;
--fs-xs:13px;  /* caption (sans) */
--fs-sm:14px;  /* body (sans) */
--fs-md:17px;  /* reading (serif, opsz auto) */
--fs-lg:19px;  /* page heading (serif, opsz 24) */
--fs-2xl:30px; /* display (serif, opsz 72) */
--fs-item:17px;/* score-sheet item number (serif 600, tnum) */
--fs-mark:23px;/* wordmark (serif 600, +0.07em) */

3. Printed form

The printed government form: a condensed black form title (think the big "Form 1040" header), heavy item numbers, and a wordmark written one letter per box, the way people fill in a paper form.

Interface and wordmark
Archivo 400/600/800 with a width axis (62 to 125). A grotesque built for informational print and screen use. Normal width for running text; condensed 75% at 800 for the form title, 87.5% for section headings and item numbers. Tabular figures.
Reading
Source Serif 4, unchanged (it is already right for the document), at 16px.
Wordmark
P R I S M in Archivo 600, each letter in a comb box drawn with the control-border grey, as on a form field.

DESIGN.md Type changes

  • Interface face changes.
  • Allow the width axis: condensed for Display, headings and item numbers only.
  • Weight 800 for Display, section headings and score-sheet item numbers (item numbers move from ink-2 to ink).
  • The wordmark is a drawn component, not a text treatment.

Stays

  • Source Serif 4 document; no italics or letter-spacing; nothing under 13px.

Weakness: Archivo's capital I and lowercase l are both plain strokes. Fine for chrome; it is not the face to show patients.

--sans:'Archivo', system-ui, sans-serif;
--serif:'Source Serif 4', Georgia, serif;
--fs-xs:13px;  /* caption */
--fs-sm:14px;  /* body */
--fs-item:15px;/* item number, 800, 87.5% wide, tnum */
--fs-md:16px;  /* reading (serif) */
--fs-lg:17px;  /* heading, 800, 87.5% wide */
--fs-2xl:26px; /* display, 800, 75% wide */
